# 期待値で買い目を選ぶ検証（2026/11/14）

過去レースの「全組み合わせの確定オッズ」を集め、AIの予測から「その組が来る確率」を学習し、
確率×オッズ（期待値）が高い組だけを買った場合を、学習に使っていない期間で確認した。

- 地方 ワイド（約2.3万レース・4期）：期待値1.0以上で 98〜104%、1.3以上で 106〜135%。学ぶ期間を入れ替えても同じ傾向。
  ただし確定オッズで計算しており、95%の幅は1.3以上でも100%を下回る。→ 本番で試験記録（scripts/evwide.py）
- 地方 馬連：84〜106%で不安定
- 中央 ワイド・馬連（約1.1万レース・7期）：学ぶ期間によって 66〜119% と大きくぶれる。採用しない

## 本命レース／穴レースの分け方（2026/11/14 追加）
期待値1.0以上のワイドの中から、AIの評価が人気以上（AI 3着内確率 ÷ 人気から見た確率 ≥ 1.0）の馬のうち、
期待値のある組に最も多く・強く絡む馬を軸にする。軸が1〜3番人気→本命レース（軸から期待値1.2以上の組）、
4番人気以下→穴レース（軸から期待値1.0以上の組）。最大5点。各期間はその期間を除いた期間で学んだ式で判定（rule2.py）。
- 地方：本命 701R 135.5%（103/224/124/86）、穴 10,761R 100.3%
- 中央：本命 42R（少なすぎて判断不可）、穴 2,616R 124.3%（期間で73〜261%とぶれる）

## 3連複（2026/11/14 追加）
期待値AIの軸を含む3連複の確定オッズを集め（地方 11,452R・中央 2,643R）、来る確率を学習（san.py）。
「期待値1.0以上の組から、来る確率の高い順に最大3点」で、各期間はその期間を除いて学んだ式で判定（san_eval.py）。
- 地方：本命レース 679R 135.0%（107/199/144/81）、穴レース 6,625R 87.1%
- 中央：本命レース 41R（少なすぎ）、穴レース 1,570R 69.8%
期待値の高い順に買うと超大穴ばかりになり、ぶれが大きすぎるため不採用。
